# EuroBaza Project — Постоянные правила для ИИ

## 1. Автоматический релиз и синхронизация PWA (Строго 4 файла)
- После любого изменения кода 14-значная версия (`YYYYMMDDHHMMSS`) синхронно обновляется сразу в 4 файлах:
  1. `version.json`
  2. `sw.js` (`CACHE_NAME = 'eurobaza-v...'`)
  3. `index.html`
  4. `admin.html`
- Запрещено менять код без обновления Service Worker кэша.

## 2. Обязательная проверка перед коммитом
- Перед любым коммитом и ответом пользователю агент обязан запустить `node check.js`.
- Ни один коммит не отправляется на GitHub, пока не будет `✅ Весь проект проверен: ошибок нет!`.

## 3. База данных Firebase и безопасность
- Актуальные правила безопасности хранятся в `EuroBaza для ИИ/Правила FireBase.md`.
- При любых доработках базы данных сверяться с этим файлом. Если требуются новые узлы или права — обновить файл и предупредить пользователя.
- Не стирать пользовательские метки прочтения сообщений при выходе из профиля (`pmOut`).

## 4. Разделение ролей Админа и Субадмина
- Субадмин (`diannakirakosyan@gmail.com` — Отдел доставки) имеет доступ только к своей переписке (`dlv`), OCR и просмотру.
- Главный админ (`vazgenstepanyan2002@gmail.com`) имеет полные права управления.
- Метки прочитанного (`ADM_DM_SEEN_ADM` и `SUBADM_DM_SEEN_DLV`) строго изолированы друг от друга.

## 5. UI и локализация
- Запрещены системные `alert()`, `confirm()`, `prompt()`. Использовать только `askC()` / `ask()` / `toast()`.
- Поддержка 3 языков интерфейса: `ru`, `hy`, `en` (в `i18n.js` и `auto-translations.json`).
- Отвечать кратко и строго на русском языке.
