1. Папка проекта: ~/storage/downloads/route
2. АВТОДЕПЛОЙ: репозиторий vazgenstepanyan2002-lgtm/rote (main). В конце каждой команды ОБЯЗАТЕЛЬНО: echo '{"v":"'$(date +%Y%m%d%H%M%S)'"}' > version.json && git add . && git commit -m 'upd' && git push
3. В конце каждой команды обновлять бэкапы (удалять старые route_backup_* и EuroBaza_FULL_CONTEXT_*).
4. Изменения делать через python3 с assert. Скрипты писать в ~ (в /tmp нет прав). Новые файлы можно создавать через cat с кавычками у метки heredoc.
5. Вместо confirm()/alert() использовать askC(текст, подпись_кнопки, иконка). Для сообщений использовать toast(текст,'ok'|'err').
6. Структура: index.html, style.css, app.js, yandex.js, ui.js, map.js, bonus.js, i18n.js, online.js, chat.js, sw.js. Экспорт/импорт удалены.
7. Окна закрываются системной кнопкой «Назад» через history.pushState/popstate. Кнопки вибрируют. Навигатор: geo:, переключатель внизу.
8. Новые тексты интерфейса нужно добавлять в словарь D в i18n.js (русский ключ -> армянский, английский).

    else document.querySelector('h2')?.appendChild(b);
    return b;
  }

    const b = ensureBadge();
    b.textContent = '🟢 ' + n;
    b.dataset.n = n;
  }

  let db = null, ref = null, hbTimer = null, renderTimer = null;
