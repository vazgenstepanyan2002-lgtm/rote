# Smart Diff Patcher Skill

Процедура максимальной экономии токенов при редактировании кода:

1. **Запрет полной перезаписи больших файлов**:
   - Никогда не переписывать целиком файлы `auth.js`, `admin.js`, `ocr.js`, `bonus.js`, `style.css` через `write_file`.
   - Использовать инструмент точечной замены `edit_file`.

2. **Принцип минимального целевого блока (Target)**:
   - В `Target` брать ровно столько строк, сколько необходимо для уникального сопоставления (обычно 3–8 строк контекста).
   - Избегать захвата больших окружающих блоков.

3. **Синхронная проверка**:
   - Сразу после применения патча выполнить:
     `node -c filename.js` или `node check.js`
   - Если замена не удалась или сломала синтаксис — немедленно исправить целевой блок без раздувания диалога.
